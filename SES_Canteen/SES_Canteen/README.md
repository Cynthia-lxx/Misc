# 食堂抢饭模拟器

这是一个基于Python和Pygame的模拟器，模拟学生们从学校各个角落冲向食堂抢饭的情景。模拟器包含两个主要功能：
1. 富有观感的人流模拟
2. 基于真实数据计算的最优抢饭路径

## 功能特点

- 可视化的人流模拟，可以看到人物从不同位置冲向食堂
- 基于A*算法的路径规划，考虑人流密度和障碍物
- 人员之间具有避障和防碰撞行为
- 可编辑的地图和人员起始位置
- 实时显示统计数据

## 安装和运行

1. 确保安装了Python 3.6+
2. 安装所需依赖：
   ```
   pip install pygame numpy
   ```
3. 运行模拟器：
   ```
   python main.py
   ```

## 操作说明

在模拟器运行时，可以使用以下按键：

- `SPACE`: 添加10个新人物
- `C`: 清除所有人
- `E`: 打开地图编辑器
- `ESC`: 退出程序

在地图编辑器中：

- `O`: 障碍物模式
- `S`: 出生点模式（人物生成位置）
- `E`: 擦除模式
- 鼠标左键: 绘制
- 鼠标右键: 绘制大型障碍物
- 滚轮: 调整画笔大小

## 代码结构

- `main.py`: 主程序入口
- `person.py`: 人物类，控制人物行为和移动
- `pathfinder.py`: 路径规划器，使用A*算法计算最优路径
- `map_editor.py`: 地图编辑器，允许自定义地图和出生点
- `config.py`: 配置文件，包含各种参数设置

## 扩展功能

你可以进一步扩展此模拟器：

1. 添加更多人物行为模式（如结队行走、跟随等）
2. 增加多个食堂选项和不同的吸引力权重
3. 添加时间因素，如不同时段人流密度的变化
4. 实现更加复杂的避障算法
5. 添加性能分析工具，比较不同路径规划算法的效果
