## 批次 4 — 细粒度回归 `CdlLinRegTrain`

- `comfydl/nodes/linreg_train.py`：从零训练 `y = X @ w + b`，mini-batch SGD + 均方损失（每步 `(y_hat - y)^2/2` 取均值）。
- 四端口：`w`(TENSOR `[f,1]`) / `b`(TENSOR `[1]`) / `loss_history`(TENSOR 1-D `[num_steps]`) / `y_hat`(TENSOR `[n,1]`)。
- 输入：必填 `X`/`y` TENSOR；可选 `dataset` DATASET（`forceInput`，存在即覆盖 X/y）；widgets `num_steps`(INT 100) / `batch_size`(INT 32, 0=全量) / `lr`(FLOAT 0.03) / `seed`(INT 0)，均"开箱可用"。
- 关键实现：节点体内 `with torch.inference_mode(False):` 跑完整训练（ComfyUI 用 `inference_mode` 包整轮 → 前向/反向/`optimizer.step()` 必须同在一个节点体内），所有输出 `detach()`，不泄漏 autograd 图。
- 验证闭环：`CdlLinRegTrain --w,b--> CdlLinReg --y_hat--> CdlSquaredLoss` 复现 `loss_history[-1]`（专项断言 allclose）；`CdlLinReg` 重算 `y_hat` 与训练 `y_hat` 一致。
- 分类：`d2l/Training`（新增分类，文档口径 125 ComfyDL 节点 / 21 分类）。
- 主冒烟 `_OUTPUT_CHECKS` 新增 `_check_linreg_train`：断言 w/b 形状、loss_history 1-D 且长度=num_steps、y_hat 形状、全部有限且 detach、整体损失下降（末半段均值 < 前半段均值/2）。`_INPUT_OVERRIDES` 给 `X`/`y` 喂匹配线性对（`y = 2*x0 - 3*x1 + 1`），避免通用 (2,3) dummy 无法 matmul。

## 关键经验（防回归）

- ComfyUI 按声明顺序位置传参 → `execute` 签名顺序必须与 `INPUT_TYPES` 严格一致；可选非 widget 类型（DATASET/TENSOR）必须给默认 `None`，否则冒烟器跳过 + 运行时调用缺参。
- 训练/推理态通道必须走连线，勿用 hidden PROMPT 自省（缓存签名只看已连线输入 → 静默复用过期缓存）。
- 可选重依赖一律 `execute` 内惰性 import，缺失抛可读提示；禁止模块加载期 import 致崩。
- 自定义训练节点必须在自身体内打开 `inference_mode(False)`，输入 `detach().clone()`，输出 `detach()`。
- `_update_readme.py` 只修正规范计数句与附录表；README/附录的 "provides N nodes across M categories" 总句与 prose 需手改，脚本匹配不到。

## 批次 5 交付：粗粒度生产回归节点 `CdlRegressionTrain`（2026-10-05）

- 位置：`comfydl/nodes/regression_train.py`（与细粒度 `CdlLinRegTrain` 并列，分类 `d2l/Training`）。
- 功能：吃 `DATASET`（可选、优先）或 X/y TENSOR（回退），一体化完成 **训练/验证切分 → 特征标准化(z-score) → mini-batch Adam 训练 → 早停(验证损失滑动均值 + 回滚最优) → 评估**，输出 `nn_model` / `mae` / `rmse` / `predictions` / `loss_history`；`save_path` 非空时存盘 `state_dict` 供推理复用。
- 设计取舍：计划要求"复用 comfy_extras 的 TrainingLoop/TrainingEvaluate/TrainingSaveParameters 栈"。但那些是 V3 `io.ComfyNode`（依赖 ComfyUI 执行上下文 / UI 预览钩子），将 `comfydl` 耦合到 rehydration 的 `comfy` 核心，会破坏 comfydl 当前与 `comfy` 的解耦并影响独立单测。故**等价复用其已验证机制**（`EarlyStopTracker` 同款滑动均值早停 + 回滚、`build_mlp` 式隐藏层构造），用纯 `torch` 自包含实现：mini-batch Adam + 验证损失早停回滚 + 可选隐藏层 MLP（`hidden` 宽度串，如 `"16,8"`）。
- **关键：标准化内嵌进模型**。`_Regressor` 把训练集 mean/std 注册为 buffer，forward 先做 `(x-mean)/std` 再跑线性/MLP 核心。返回的 `nn_model` 自包含，直接喂原始特征给 `CdlNNForward` 即复现训练期预测；存盘 `state_dict` 含标准化参数，可独立重载。
- 默认 widgets（开箱即用）：`lr=0.1`、`steps=500`、`batch_size=0`(全批)、`test_size=0.2`、`standardize=yes`、`hidden=""`(线性)、`loss=mse`、`early_stop_patience=30`、`early_stop_min_delta=1e-4`。调参注记：初版 `lr=1e-2` 在 300 步内对精确线性问题收敛不足（MAE 0.6）；因默认标准化使特征良态，调高到 `lr=0.1` 后 500 步 MAE≈4e-3（验证集近乎完美拟合），故定此默认。
- 验证：主冒烟新增 `_check_regression_train`（断言 nn_model 为 nn.Module、mae/rmse 有限标量且对精确线性问题 <0.1、predictions 形状 [n,1]、loss_history 非空 1-D）；双端全量冒烟 **299 PASS / 33 SKIP / 0 FAIL**。专项 `test_regression.py` 扩至 32 项全绿（含 DATASET 路径、nn_model 自包含复现、save/reload 往返）。
