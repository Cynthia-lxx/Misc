## 二、探索期查清的机制（易忘，全部实测）

1. **Templates 数据链**：前端 `api.getCoreWorkflowTemplates(locale)` → `GET /templates/index.json`（或 `index.<locale>.json`，404 时回退英文）→ `server.py` 按版本分支：
   - `use_legacy_templates`（安装包版本 < 0.3.0，当前 0.1.61 → **True**）→ `web.static('/templates', legacy_templates_path())`；
   - 否则 → `FrontendManager.template_asset_handler()`（资产表逐文件服务）。
2. **此前面板为何空白（两层根因）**：
   - 表层：`comfyui_workflow_templates` **元包里没有 `templates/` 目录**（数据实体在 `comfyui_workflow_templates_json`），legacy 静态路由挂在不存在的路径上 → 所有 `/templates/*` 请求 404；
   - 深层：即使切到新式分支，521 个官方模板中 **519 个引用脱水后已删除的节点**（剔除前端内置类型 Note/MarkdownNote/PrimitiveNode/Reroute 与内嵌 subgraph 定义后逐一核对；幸存者仅 `basic_mask_operations_and_compositing`、`utility_image_stitch`）。
3. **`/workflow_templates` 通道证伪**：`custom_node_manager` 只扫 `custom_nodes/` 目录与 `load_custom_node` 模块；comfydl 是内置模块（`init_builtin_dl_nodes` 直 import）→ 恒返回空。旧记忆「example_workflows = 模板数据源（经 :104 glob）」已作废修正。
4. **侧边栏分区**：`All`/`Popular`（flame 图标）前端硬编码；`isEssential:true` 分类进顶部分组；非 essential 按 `type` 归 GENERATION TYPE；分类图标是运行时拼接的 `icon-[lucide--*]` 类名。
5. **schema 关键点**：`index.schema.json` 的 `templateInfo.name` 模式 `^[a-zA-Z0-9._-]+$` **不允许空格**。~~运行时空格可用~~ **此判断被当日实测推翻，见 §七**。`mediaType` 枚举只有 image/video/audio/3d（LM 文本工作流用 image）。
6. **缩略图 URL 约定**：前端默认模块请求 `/templates/<name>-1.<mediaSubtype>`；我们的封面文件是 `<name>.jpg`（无 -1）→ `_THUMBNAIL_FILENAMES` 显式映射（Load and Chat 暂借用 Train and Chat 封面）。
7. **前端图标可用集**：已构建 CSS 实测 **233 个 lucide 图标**（含 graduation-cap / book-open / dumbbell / scroll-text / brain ✗ 不存在）。占位图标用 `icon-[lucide--graduation-cap]`，最终清单交付用户挑选。

## 七、当日返修：模板点击打不开（§五验收暴露）

**现象**：官方模板正常打开；我们的两张点击无反应。用户判定"工作流损坏"。

**诊断**：JSON 本身严格合法（无 NaN/Infinity）、结构标准（version 0.4 UI 格式）、节点全在注册表（T8 曾过）——文件没坏。真正根因在 **HTTP 层**：

1. 前端 `fetchTemplateJson`（settingStore chunk）直接拼 `/templates/${name}.json` **不做编码**（settingStore-KkBYyEnh.js 实测）；
2. 浏览器把空格转义为 `%20` 发出；
3. **aiohttp 动态路由 `{path:.*}` 的 match info 只解码 `%2F`/`%25`**（`web_urldispatcher._unquote_path_safe`，源码 1269 行），`%20` 原样到达 handler → 带字面 `%20` 的字符串白名单匹配失败 → 404；
4. 前端 `.json()` 解析 404 文本抛异常 → `loadWorkflowTemplate` catch 后 `console.error` + **静默 return false** → 点击无任何反应。

官方模板文件名全 ASCII 安全字符，编码后不变，所以能开——完美对照。这正是官方 schema 禁空格的深层原因（不是 CI 洁癖）。

**修复（双管齐下）**：
- `git mv` 重命名：`language_model_train_and_chat.json` / `language_model_load_and_chat.json`，封面直接命名 `language_model_train_and_chat-1.jpg`（命中前端缩略图 URL 模式，`_THUMBNAIL_FILENAMES` 只剩 load→train 复用一条）；
- `build_handler` 入口 `unquote(match_info)` 兜底（防未来非 ASCII 名；traversal 防护是 resolve+is_relative_to 路径级，解码安全）。

**测试盲区教训**：上一轮 T5 只测纯函数层（直接传解码后的名字），没经过 aiohttp 路由层，编码问题必然漏检。本轮新增 **T9 路由层集成测试**（aiohttp TestServer 真发 HTTP）：`%5F` 编码 URL 必须 200（等价复现原 bug）、错误编码/未知/穿越 404、官方资产对照 200。测试从 28 → **42 项全过**；全量冒烟 279 PASS / 23 SKIP / 0 FAIL 不变。

**通用教训**：凡涉及「前端拼 URL → aiohttp `{xxx:.*}` 路由 → 文件查找」链路，① 文件名只用 `[a-zA-Z0-9._-]`；② handler 必须 unquote；③ 测试必须打到真实路由层。同类坑：`web.static` 的 StaticResource 同样只解 `%2F`/`%25`（源码 646 行），带空格/中文的静态文件同样 404。

## 八、节点实时进度报告（用户新需求）

**需求**：为"各个推理、训练等节点"加实时进度报告。先按要求查文档，再动手。

**文档结论**：`ComfyUI_Docs_Work/zh/custom-nodes/v3_migration.mdx` 给的是 V3 路径
`await api.execution.set_progress(...)`——**但它是 async**，而本仓库节点是 V1 风格同步 `execute`，
照搬会卡住（sync stub 每次调用要建线程池 + 事件循环，每步一次太贵）。

**最终机制**（读宿主源码后确定，官方内置节点的通用做法）：
- `main.py` 的 `hijack_progress(server_instance)` 注册全局 hook；
- hook 内用 `comfy_execution.utils.get_executing_context()`（**contextvars**）自动解析**正在执行的节点**
  → 节点侧只写 `comfy.utils.ProgressBar(total)` + `pbar.update(1)`，**完全不必知道自己的 node_id**；
- **副产品（价值最大）**：同一个 hook 会执行
  `model_management.throw_exception_if_processing_interrupted()` → **凡上报进度的循环自动变成可被 UI
  "取消"打断的循环**，直接解决了"训练/长生成无法中断"的老问题；
- `ProgressBar` 自带节流（100 ms / 0.5%，首末必发），构造时捕获 hook，**无 hook（裸解释器、冒烟测试器）
  时是 no-op** → 同一份代码无头可跑，测试不用改。

**改动清单**（4 个长耗时节点 + 1 个协议函数）：

| 节点 | 文件 | 循环 | 上报单位 |
|---|---|---|---|
| Training Loop | `comfy_extras/nodes_training.py` | 优化器步 | 每步 |
| Language Model: Train | `comfy_extras/nodes_lm.py` | 优化器步 | 每步 |
| Language Model: Generate | `comfy_extras/nodes_lm.py` | 生成 token | 每 token |
| Sliding Window | `comfy_extras/nodes_nlp.py` | 流位置 | 每样本 |

`comfy/lm_protocol.py::generate_tokens` 新增可选 `progress(done, total)` 回调（**不 import 任何 UI 机制**，
保持协议层只依赖 torch——与脱水规则一致），节点侧传入转发到进度条的 lambda。
