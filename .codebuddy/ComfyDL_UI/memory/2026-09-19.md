## B. 关键决策与踩坑
1. **布尔 mask 语义**：本节点采 `F.scaled_dot_product_attention` 现代约定（True=可注意），与
   `torch.nn.MultiheadAttention`（True=屏蔽）**相反**——torch 2.13 实测确认（含 fast path），additive
   浮点掩码两侧一致。冒烟断言对照 `nn.MHA` 时须取反。屏蔽位填 `finfo.min`（非 `-inf`）→ 全屏蔽行
   softmax 出均匀分布而非 NaN。
2. **显式 softmax 不走 fused SDPA**：保证带种子 dropout 与 mask 语义在所有后端逐位一致；数值上与
   SDPA 一致（实测最大偏差 1.9e-6）。
3. **extras 跨模块导入必须绝对导入**：该分支 `load_custom_node` 忽略 `module_parent`、按文件路径命名
   模块，相对导入必炸「no known parent package」；改为 `from comfy_extras.nodes_normalization import …`
   （与 `nodes_latent` 先例一致）。
4. `_rerun_v3` 重跑时未显式传入的张量输入会**重新随机** → 断言依赖一致性时须全量传入。
5. 测试脚本两次"失败"均为脚本自身 bug（无 bias 输出对照带 bias 的 `nn.MHA`；affine 参考漏了 ln1），
   实现本体与 SDPA 完全一致。

## B. 关键决策
1. **spec 链架构**：`inference_mode` 约束下训练必须单节点体内闭环 → 结构以冻结 dataclass 链走
   `MODELSPEC` 槽（纯值可缓存），Build 物化，Train 在 deepcopy 上跑闭环返回**新** eval 模型（缓存安全，
   冒烟 pin 住"输入模型未被污染"）。
2. **Embedding 接已有链 = 替换嵌入链接点保留块**（文档语义与实现修正为一致）。
3. **复用**：Train 吃 step6 `OPTIMIZER` 槽；生成输出 ids TENSOR + 可选解码文本（文本无关）。
4. **逐位置交叉熵**：每 token 预测后继，一次前向全序列监督 → 300 步默认即收敛（实测 50 步 4.38→0.035）。
5. **贪心与温度采样都确定性**（本地 Generator + seed）；dropout 只在 train 态且受 trainer 种子控制。
