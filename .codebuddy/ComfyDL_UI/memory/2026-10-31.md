### 本批次踩坑（新）
- **WMI 陷阱**：RamProvider 首版在 poll 里调 `platform.system()` → Windows 上走
  `platform._wmi_query` 可阻塞采样线程数十秒（WMI 服务冷时）——已改 `sys.platform`
  并写入 provider docstring 与测试断言（T4g）。排查手段：`sys._current_frames()` 转储
  卡死线程栈，一击定位。
- **`_push` 禁止热导入 server**：采样线程内 `from server import PromptServer` 会拖全量
  应用导入且失败导入不缓存、每 tick 重试——已改为仅 `sys.modules` 已加载时晚绑定。
- **路由 409 语义**：`set_enabled(False)` 返回 False 与"硬禁用拒绝"不可混用同一判定，
  需独立 `is_hard_disabled()` 检查。
- **stop() 需要 join**：控制路由的 running 应答依赖 stop 返回即真。
