### 3.2 实现机制（改造点极小）

- ComfyDL 包结构对内置天然友好：顶层 `__init__.py` 相对导入 + 自插 sys.path（`_PLUGIN_ROOT`），`nodes/__init__.py` 用 `importlib.import_module(f'.{mod}', package=__package__)` 动态聚合子模块；仓库根启动时 `comfydl/` 在 sys.path，`import comfydl` 即自洽。

## 6. 环境与运行经验（务必阅读，省大量踩坑时间）

- **运行环境**：venv `P:\Dev\ComfyUI_Refs\ComfyDL_UI\penv`（无句点）Python 3.14；嵌入式兜底 `P:\python-3.14.5-embed-amd64`（或 `P:\python.ps1`）。本机**无 GPU**（CPU 版 torch），启动建议 `--cpu`（model_management 已自动降级可省）。
- **常用验证命令**：
  - 快速注册复刻：上面 §3.3 第 1 条（数秒级，不启动完整 server）。
  - 完整冒烟：`penv\Scripts\python.exe -u main.py --cpu --port 18188 --disable-auto-launch` 后用 `Invoke-RestMethod http://127.0.0.1:18188/object_info` 查节点数；务必 `--database-url sqlite:///…` 隔离 db。
  - E2E：`.codebuddy/scripts/e2e_verify.py`。
- **db lock 教训**：默认 db `user/comfyui.db` 若被本机其它常驻 ComfyUI 进程占用会报 `Could not acquire lock on database … Another ComfyUI process may already be using it`，DB 初始化失败但 server 仍以 RAM 模式能起——冒烟请用 `--database-url` 指向独立文件。
- **stdout 捕获教训**：ComfyDL banner 是 `print`→stdout；把进程 stdout 重定向到文件且随后 `Stop-Process -Force` 杀进程时，Python 块缓冲未 flush 会丢 banner 内容（曾观察到 stdout 日志为空）。冒烟脚本务必 `python -u`（无缓冲）或用 `PYTHONUNBUFFERED=1`。
- **执行环境教训**（CodeBuddy 工具侧）：
  - 长驻/后台型命令（Start-Process、长轮询、跑几分钟的脚本）常被用户转"后台执行"或触发审批超时，**stdout 对当前会话不可见**；解决办法：让命令把关键结果**写入临时文件**，再用 read_file 读文件取结果。
  - `web_fetch` 无法访问本机 `http://127.0.0.1`（平台侧抓取），探测本地服务请用命令内 `Invoke-RestMethod`/urllib 并把结果落盘。
  - 本仓库 git 由管理员创建：日常 git 命令需带 `-c safe.directory=P:/Dev/ComfyUI_Refs/ComfyDL_UI`。
  - PowerShell 5.1 中 `& $arr` 不能对参数数组 splat（会把整串当命令名报错）；cmd 下 `&&` 会被工具翻译成 `;` 破坏 git 命令串——**每条 git 命令单独写全**。
- **GBK/emoji 双保险**：宿主 `main.py` 已 UTF-8 reconfigure（`744c25a`）+ ComfyDL banner 已去 emoji（`adc3c81`），在默认 GBK 控制台启动不应再崩；若将来给启动输出加新字符，避免 emoji、避免非 GBK 可编码字符。
