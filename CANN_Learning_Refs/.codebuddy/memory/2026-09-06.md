### main.asc:89 编译 warning 来由（`'cce_global' attribute ignored when parsing type`，共 3 条，无害）

### 融合归约设计要点（arch §1.2/§1.3，落码守则）
- 每轮 GetTensorC 得 (baseM×baseN) fp32 tile（UB row-major 连续）。**每 tile 行内 max over N**：行=baseN fp32；fp32 elementNumPerRep=64 → baseN>64 拆 chunk≤64 逐段 `ReduceMax(part,rowSeg,tmp,cnt)`（dst 单元素）+ `Max` 合并，天然吸收任意 N（含尾 N）。
- **running-max 跨 N 块**：UB 缓冲 = singleCoreM 个 fp32，元素级 `Max(running, running, tileRowMax, count)` 合并；N 向全部块到齐（每核覆盖整 N=singleCoreN）后 running-max=每行最终 max → `ReduceSum(running, singleCoreM)` 64-chunk 累加得行段部分和。
- 行块全局行号推式（FIRSTM，R2 真机裁决项）：`mBlockIdx = count % roundM`，tile 对应行起点 = mBlockIdx*baseM。
- **初值**：MaxSim 初值禁 0 → running-max 用 `Duplicate(running, -FLT_MAX, singleCoreM)` 或首 tile 直写；全负行须返回最大负数（-inf 初值正确）。
- 归约方向铁律：先每行 max over N、再跨行 sum over M（impl.py `np.max(axis=-1)` 后 `np.sum(axis=-1)`）。
- M 尾块（<16 行）/K%16==8（K=8×odd）按 arch §3：内置 vector dot/vector 修正回退，真机裁决 R1/R4 后开 cube 直跑。
- 尾块策略风险明确：tile 高度恒 baseM 的整除语义是库确定遍历前提；M/N 非 base 倍数时先走「M/N 对齐主区 + 尾块兜底」路线，真机先验对齐 case。
