    CLI 命令Web 操作说明
    
              
                
    /help /?本页命令与快捷键说明
    
                
    /setkey设置 → API Key留空保持原值
    
                
    /config设置 → 当前配置API Key 脱敏展示
    
                
    /model设置 → 模型deepseek-chat / deepseek-reasoner 等
    
                
    /clear历史 → 清空历史同时清空服务端上下文
    
                
    /show会话历史 / 时间线完整消息，含代码预览
    
                
    /copy /cp输出 → 复制代码浏览器剪贴板 + 系统剪贴板兜底
    
                
    /clipboard /cb读剪贴板读取系统剪贴板填入题面
    
                
    /file [路径]读取路径 / 载入文件相对路径基于工作区
    
                
    /save [路径]保存 .cpp自动补 .cpp 后缀与创建目录
    
                
    /exit /q关闭标签页服务由 Ctrl+C 停止
    
                
    （新增）分析 → 分析内存 / 复杂度 / 风格冗余 / 性能体检；可选实测（内置 MinGW64）；每次分析自动一次短 AI 汇总

    Ctrl + L

    关于
    
              
    纯本地服务：Python 标准库 http.server + openai SDK，零新增依赖、零构建步骤。服务仅监听 127.0.0.1，配置与历史存于用户主目录。
    
              
    分析能力全部本地执行：内存/复杂度/风格/性能四类静态估算 + 可选的内置 MinGW64 编译实测；AI 仅在分析后做一次限量短汇总。分析指标不外发。
    
              
    界面样式参考 UI Reference Kit（MIT 派生，见 vendor/LICENSE-MIT.txt）：配色/排版/动效 token、9 套主题与 ui-button 组件。分析视图信息架构参考 ComfyDL_UI profiling（三色判定、unknown 诚实标注、手动触发 + 缓存、master switch）。
