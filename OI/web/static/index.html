      CLI 命令Web 操作说明
      
              
                
      /help /?本页命令与快捷键说明
      
                
      /setkey设置 → API Key留空保持原值
      
                
      /config设置 → 当前配置API Key 脱敏展示
      
                
      /model设置 → 模型deepseek-chat / deepseek-reasoner 等
      
                
      /clear历史 → 清空历史同时清空服务端上下文
      
                
      /show会话历史完整消息，可一键载入编辑器
      
                
      /copy /cpIDE → 复制浏览器剪贴板 + 系统剪贴板兜底
      
                
      /clipboard /cbAI 生成弹层 → 读剪贴板读取系统剪贴板填入题面
      
                
      /file [路径]IDE → 打开（弹层）相对路径基于工作区
      
                
      /save [路径]IDE → 保存 ⌃S自动补 .cpp 后缀与创建目录
      
                
      （新增）IDE → 运行 F5 / 调试 F9stdout/stderr 分流；gdb 断点、步进、变量与监视（内置 MinGW64）
      
                
      （新增）IDE → 分析 A内存 / 复杂度 / 风格冗余 / 性能体检 + 一次限量短 AI 汇总
      
                    
            
      
          
      
          
      
            
      
              
      快捷键
      
              
      
                
      F5
      运行（stdout / stderr 分流）
      
                
      F9

      F10 / F11
      调试步过 / 步入
      
                
      Ctrl / ⌘ + Enter
      AI 生成（弹层，流式写入编辑器）
      
                
      Ctrl + S
      保存当前编辑器内容
      
                
      Ctrl + B
      在当前行切换断点
      
                
      Ctrl + G
      跳转到指定行
      
                
      Ctrl + K
      命令面板
      
                
      Ctrl + L
      打开 / 关闭事件日志
      
                
      H / A / S / ?
      切换次要视图（输入框外）
      
                
      Esc
      关闭弹层 / 日志 / 结束运行
      
              
      
            
      
            
      
              
      关于
      
              
      纯本地服务：Python 标准库 http.server + openai SDK。服务仅监听 127.0.0.1，配置与历史存于用户主目录。前端唯一第三方依赖是离线内置于 static/vendor/codemirror/ 的 CodeMirror 5。
      
              
      运行与调试由内置 MinGW64（GCC 4.9.2 + gdb/gdbserver）完成：编译产物按内容哈希缓存，stdout/stderr 分流实时显示；调试为 gdbserver 托管 + GDB/MI 驱动，支持断点、步进、变量与监视。所有指标不外发。
      
              
      界面样式参考 UI Reference Kit（MIT 派生，见 vendor/LICENSE-MIT.txt）：配色/排版/动效 token、9 套主题与 ui-button 组件。分析视图信息架构参考 ComfyDL_UI profiling（三色判定、unknown 诚实标注、手动触发 + 缓存、master switch）。
