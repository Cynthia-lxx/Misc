# 2026-11-15 · 云 IDE 改版（设计基线与踩坑）

把控制台从「5 视图切换」重构为**以代码为中心的云 IDE 主页**。本文详录本轮决策、架构与全部踩坑；上一轮分析工具设计见 `2026-11-15-analysis-tools.md`。

## 需求与用户裁决

- 开箱即用的功能不切换选项卡：代码居中，内存/复杂度等关键指标 + AI 辅助与代码同屏；高级/次要工具进次要选项卡。
- 高频操作给快捷键。
- 做成云 IDE：运行 + 输入输出（stdout/stderr **分流**）+ 调试（**断点**）+ 基本文件保存/读取。
- 三问三答（2026-11-15）：调试 = **真实 gdb 断点调试**（GDB/MI 驱动内置 gdb.exe）；编辑器 = **CodeMirror 5 vendor 进 static/vendor/**（第一个也是唯一的前端第三方依赖，离线）；视图 = **IDE 即主页**，分析完整报告/历史/设置/速查降为次要选项卡；用户点名**多利用 Overlay**——适合的内容用叠加层而非切页。

## 后端新增

- `toolchain.run_program()`：exe 按内容哈希缓存（`%TEMP%/oi-run-cache`，LRU 16）+ 失败回退 `<digest>-fb` 持久目录（**不能用 TemporaryDirectory**，exe 会在使用前被删）；stdout/stderr 双管道分流；`MAX_RUN_OUTPUT=64KB`。
- `analyzer/debugger.py`（gdbserver 架构，见踩坑 1）：编译 `-g -O0` 缓存于 `%TEMP%/oi-debug-cache` → `gdbserver --once 127.0.0.1:<port> main.exe`（子进程 stdin/stdout/stderr 经 gdbserver 管道转发）→ `gdb --interpreter=mi2` → `-file-exec-and-symbols` → `-target-select remote` → `-break-insert` → `-exec-continue` 跑向首断点。变量 `-stack-list-variables --simple-values`，监视 `-data-evaluate-expression`，步过/步入/步出，空闲 15 分钟回收，taskkill /T 清树。stderr tap 过滤 gdbserver 自身诊断（Process created/Listening/Child exited 等）但保留原始缓冲供启动探测。
- 路由：`POST /api/run`、`POST /api/debug/start|command|stop`、`GET /api/debug/info`。

## 关键踩坑（重要，后续会话必读）

1. **mingw gdb 的 I/O 重定向是假的**：`-exec-run < in.txt > out.txt` 返回 `^error,msg="Invalid argument: <"`；console 透传 `run < in > out` 只**回显**不落盘（out.txt 根本不创建）。此 gdb（TDM 4.9.2 附带）必须用 **gdbserver 托管子进程** 方案：I/O 走 gdbserver 管道（实时、分流），gdb 只管调试控制。
2. **异步 `*stopped` 无人消费**：断点命中记录躺在 MI 队列里，前端看到 status=running 永远不动。所有 `command()` 处理前必须 `_drain_async()`（非阻塞排空）；否则会误判「断点没命中」。
3. **MI 读取必须带超时**：裸 `readline()` 在 gdb 不输出时永久阻塞（deadline 只在两次读之间检查）。用后台泵线程 + `queue.get(timeout)`。
4. **Popen 必须 `text=True`**：二进制模式下 `line.strip() == "(gdb)"` 永远 False（bytes vs str），曾导致横幅循环无限阻塞。
5. **editor.js 动态注入的 codemirror.min.css 排在 ide.css 之后**，同特异性会赢 —— CM 主题选择器必须加 `.ide-editor-host` 前缀提特异性。
6. **token 名**：本项目只有 `--ui-surface/surface-raised/surface-sunken/border/text/text-muted/accent*`，**没有** `--ui-bg/--ui-primary/--ui-radius/--ui-font`；语义色 `--state-error/warning/success` 在 tokens.css:76。
7. **`/api/generate` 契约**：body 是 `{input, new_topic}`（不是 prompt）；SSE 事件为 `{type:"start|delta|error|done", text|message|code}`，done 里带后端解析好的 `code`。
8. **PowerShell `Get-Content -Raw` 不带 `-Encoding UTF8` 会把中文读成 GBK 乱码**，喂给 playwright eval 后含中文比较/点击全部静默失败（filled=false / clicked=false 假象）——含中文的 eval 脚本必须 `-Encoding UTF8`。
9. **playwright-cli eval 参数含 `;` 的单行代码会 SyntaxError**，复杂脚本一律落盘文件再 `(Get-Content file -Raw -Encoding UTF8)` 传入。
10. stdio 转发的行缓冲：gdbserver 按行转发 stdin，写入文本统一补尾 `\n`（`_write_stdin`）；目标 stopped 在入口时 stdin 不转发，必须先 continue。
